# 黑话编译器 · 核心词典（手工维护）
#
# 格式：一行一个词条    词 | 类别 | 映射 | 备注
#   映射和备注可以省略；以 # 开头的行是注释。
#
# 类别：
#   修饰    膨胀修饰语：不携带信息，死代码消除时整个删掉（不需要映射）
#   空动    空洞动词：映射写它的"上位词"——另一个词条，或者一个朴素的说法；降级时沿着映射一路走到朴素说法
#   空转    和虚指名词搭配时整句没有信息的动词（形成闭环、实现新突破）；映射同空动
#   虚名    虚指名词：映射同空动
#   固定    名词性的固定搭配：映射写它的大白话，常量折叠时整体替换
#   固定动  动词性的固定搭配：同上
#   实动    本来就朴素的动词（让句式分析认得它是动词）
#   内容    普通词：本身不用改，登记它只是为了防止里面的字被误切成功能词（比如"认为"里的"为"）
#   以 为 为了 作为 围绕 通过 在 把 让 的 并列 主语 情态 连接
#           功能词：句式分析靠它们认出"以 X 为抓手""围绕 X"这样的结构。只能在核心词典里定义。
